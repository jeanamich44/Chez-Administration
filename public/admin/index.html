Règles & Limites des Rechargements

Comptes SumUp (CB)

Les deux banques doivent être complètes en base. Si une clé manque au démarrage, le bot crash. Coche celle utilisée pour les paiements CB.

Durée de validité du lien CB SumUp. Stockée en table (general.sumup_expiration_minutes).

OxaPay (Crypto)

Stockée uniquement en base (oxapay.api_key). Si elle manque au démarrage, le bot crash.

Tarifs IPTV & Configuration API

Le haut du message (Host / Username / Password) reste fixe. Ce bloc s’affiche en dessous, en texte brut.
Coche Compte actif sur un seul compte. Seul celui-là est utilisé. Enregistre d’abord, puis teste (clé API, sans créer de ligne). S’il échoue à l’achat, erreur client et aucun débit.
Même principe que les clés API : plusieurs comptes, un seul actif. Enregistre d’abord, puis teste la connexion (cms-4k.com + Geetest, comme sur le site). Les achats payants restent sur le compte API actif.
